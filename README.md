# 🫧 BubbleLay - Simple Stream Overlay

BubbleLay is a lightweight and easy-to-use stream overlay designed 
for OBS and other streaming software. It displays chat messages 
as animated bubbles on your stream.

## ✨ Features
- 🫧 Bubble-style chat overlay
- 🎨 Clean and minimal UI
- ⚡ Lightweight and performant
- 🖥️ Easy to set up and use
- 🔧 Customizable settings

## 📥 Installation
1. Go to [Releases](https://github.com/Devseyo/Simple-Stream-Overlay/releases)
2. Download the latest `BubbleLay_Installer.exe`
3. Run the installer
4. Follow the setup wizard (Next → Next → Finish)
5. Launch BubbleLay from your desktop shortcut

## 🖥️ Requirements
- Windows 10 or later
- .NET 8.0 (included in installer)

## ⚠️ Notes
- Windows may show a SmartScreen warning
- Click "More info → Run anyway" to proceed
